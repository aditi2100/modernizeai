# ModernInventory reference application

This is a separately maintained, layered Spring Boot REST example. It is a reference
target—not output generated by the ModernizeAI demo agent. It has request validation,
controller/service/repository boundaries, OpenAPI UI, and JUnit service tests. The
default local profile uses in-memory H2; `DATABASE_URL`, `DATABASE_USER`, and
`DATABASE_PASSWORD` can configure PostgreSQL-compatible JDBC settings.

Run with Maven and Java 17+:

```bash
mvn test
mvn spring-boot:run
```

OpenAPI UI: http://localhost:8081/swagger-ui.html
